# Todoin App 📝

Aplikasi Desktop pencatat tugas (Todo List) offline-first yang dibangun untuk belajar kolaborasi Frontend dan Backend.

## 🛠️ Tech Stack

- **Frontend:** Python (Menggunakan framework [Flet](https://flet.dev/))
- **Backend:** Golang
- **Database:** SQLite

## 📂 Struktur Project

```text
todoin-app/
├── frontend/       # Aplikasi Desktop (Python)
├── backend/        # API Server (Golang) - (atau 'server/')
├── .gitignore
└── README.md
```
